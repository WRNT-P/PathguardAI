```dart
// gps_reporter.dart — ⚠️ ไม่เคย compile
Timer? _heartbeat;

Future<void> startGpsReporting() async {
  // ... ของเดิม ...
  _heartbeat ??= Timer.periodic(const Duration(seconds: 60), (_) async {
    final last = await Geolocator.getLastKnownPosition();
    if (last != null) await _send(last);
  });
}

Future<void> stopGpsReporting() async {
  await _sub?.cancel();
  _sub = null;
  _heartbeat?.cancel();
  _heartbeat = null;
}
```

`_send` มี throttle 20 วิอยู่แล้ว เลยไม่ยิงซ้ำกับ stream

### 🟡 5.5 คำขอเดินทางค้าง `pending` ถาวร

grep `apiPatch` ทั้งแอป — มีแต่นิยามใน `api_client.dart` **ไม่มี call site เลย**

ผล: ทุกแถวใน `trip_requests` เป็น `pending` ตลอดกาล · alert `trip_denied` ไม่เคยเกิด ·
`GET /api/patients/{id}/trip-requests` ที่ผู้ดูแลจะเห็นค้างหมด · **C-3 Confidence Score
ที่รายงานอ้างอิงไม่เคยถูกบันทึกผลการตัดสินใจ**

Firebase เป็นตัวส่งสดต่อไปได้ — แค่ขอให้ยิง `PATCH /api/trip-requests/{id}` ด้วย
`{"decision": "approve"}` หรือ `{"decision": "reject"}` ตอนผู้ดูแลกด (สัญญา §9)

### 🟡 5.6 `patient_id` อาจเป็น null

`trip_approval_service.dart:16` ส่ง `Session.instance.patientId` ตรง ๆ ไม่เช็ค null
(ต่างจาก `sos_service.dart:6` ที่เช็ค) → ถ้า session หายจะได้ 422

## 7. `AUTH_ENABLED` — ใกล้เปิดได้แล้ว

เหตุผลที่ล็อกไว้เมื่อ 30 ส.ค. คือ *"ฝั่งผู้ดูแลไม่มี Firebase Auth เลย `currentUser`
เป็น null"* — `a96a841` ปิดข้อนั้นไปแล้ว

- register — `createUserWithEmailAndPassword` แล้ว `POST /api/register` ด้วย uid เดียวกัน
  → ผ่าน check ที่ `users.py:44`
- login — `signInWithEmailAndPassword`
- คนไข้ — `signInWithCustomToken`
- `api_client.dart` แนบ Bearer ทุก request
- `POST /api/pair` เป็น unauthenticated by design → header ว่างไม่มีผล

**เหลือแค่ 5.1–5.6 กับการเปลี่ยนไปใช้ `GET /api/me`** แล้วเราจะเปิดได้
จะบอกล่วงหน้าก่อนเปิดเสมอ ไม่เปิดเงียบ ๆ
